IoT Smart Energy Meter

A B.Tech CSE (DS+AI) project at Shri Ramswaroop Memorial University. An ESP32 reads AC voltage and current through sensors, converts them with its ADC and shows the readings on an I2C LCD. I extended the base build with energy (kWh) and cost calculation, a Blynk dashboard and a Telegram bot.

View source on GitHub ↗
Supply + load→Sensors→ADC→ESP32→I2C→LCD

Components

  • ESP32: main controller
  • ACS712: Hall-effect current sensor
  • ZMPT101B: transformer-based AC voltage sensor
  • 16×2 LCD with I2C module
  • Breadboard and jumper wires

My extensions

  • Power, energy (kWh) and running cost
  • LCD alternates V/I/P and Energy/Cost
  • Blynk dashboard with live gauges
  • Telegram bot: /status, /reset

Concepts applied

  • Sensor interfacing
  • Analog-to-digital conversion
  • Embedded processing
  • I2C serial communication

Limitations

  • Sensors need calibration
  • Accuracy depends on the sensors used
  • ESP32 needs a stable power supply

Next steps

  • Overload detection and alerts
  • Cloud storage of readings
  • Better calibration and accuracy
